RFC 5280 §6.1
PKI ARCHITECTURE

How Digital Trust is Established

RFC 5280 path validation establishes mathematical and policy trust through hierarchical certificate chains.

1. End-Entity Server

Presents public key and SANs to client TLS sockets (isCA=false).

2. Intermediate CA

Authorized issuing CA that signs leaves and isolates the root key (isCA=true, keyCertSign).

3. Root CA Anchor

Self-signed, highly secured trust anchor pre-installed in OS and browser trust stores.
